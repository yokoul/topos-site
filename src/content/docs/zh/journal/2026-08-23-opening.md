今天，Topos 的代码仓库公开，第一个版本打上了标签，这个网站上线了。具体意味着什么，说明如下。

## 已上线

- **代码**，MIT 许可：2D/3D 定位，PSN、OSC、ADM-OSC 和 WebSocket 输出，激光测距仪校准，仪表盘，以及无需硬件即可试用的模拟模式。296 个测试，CI 覆盖 Python 3.11 与 3.12。
- **基站固件**和 OpenSCAD + STL 格式的**外壳**，CERN-OHL-P 许可。
- **完整指南**，从订购模块到场馆校准，每次构建网站时从代码仓库导入 — 不会与代码脱节。
- **路线图**，包括我们不会做的事。

## 还缺什么

照片。打印好的外壳、架设在舞台上的基站、演员身上的标签。它们会来的 — 要拍好必须在剧院里。视频也一样。

指南的法语和中文翻译。英文已就绪；其余的逐页推进。

## 已知需要改变的

Topos 自春季起在 Douze Dix-Huit 投入演出使用。最初几场演出暴露了两件事。

**安装**步骤仍然太多，守不住五分钟的承诺。我们有一份清单；它会变成 issue。

**Art-Net** — 直接从 Topos 驱动电脑灯 — 经由 Soma 可行，现场直接驱动则失败了。在 Topos 一侧管理灯具会叠加多层误差，这也不是一个空间翻译器该做的事。我们很可能把 Topos 收束到它擅长的事 — 位置 — 把灯具控制交给控台或 Soma。在路径明确之前不会移除任何东西。

## 为什么现在开源

因为它能用，而不是因为它完成了。一家想要定位的社区剧院没有封闭方案的预算，也不需要它们的复杂度。如果 Topos 能服务于我们之外的舞台，早知道比晚知道好 — 也希望那个舞台告诉我们哪里不对。
