    <h2>五个步骤，一台激光测距仪，一个下午。</h2>
    <p>所需的一切都在本站：打印文件、固件、指南。没有专有技术，没有线上买不到的东西。</p>
    <a class="sl-link-button primary" href="/zh/start/01-hardware/">阅读指南</a>
  </div>
  <ol class="tp-steps">
    <li><div><b>订购模块</b><span>基站用三个 MaUWB ESP32-S3，每位演员一个 MaUWB Direct，均购自 Makerfabs。另备 USB-C 线和电源。</span></div><small>物流</small></li>
    <li><div><b>打印并组装三个基站</b><span>提供 STL，MaUWB ESP32-S3 模块，底座 + 卡扣盖。</span></div><small>打印</small></li>
    <li><div><b>烧录并连接 WiFi</b><span>首次通电时进入配网页面。换场馆无需重新烧录。</span></div><small>10 分钟</small></li>
    <li><div><b>用激光测距仪测量，以毫米输入</b><span>Topos 通过三边测量推算基站位置。</span></div><small>15 分钟</small></li>
    <li><div><b>连接控台</b><span>PSN 到 grandMA、Augment3d 或 Soma，OSC 到 QLab，Art-Net 到电脑灯。</span></div><small>5 分钟</small></li>
  </ol>
