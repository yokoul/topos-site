## Un projet qu'on construit avec les salles

Topos tourne dans un théâtre. Il deviendra meilleur avec d'autres plateaux, d'autres consoles, d'autres géométries d'ancres que les nôtres. La contribution la plus utile n'est pas du code : c'est de raconter ce qui s'est passé chez vous.

## Contribuer

Docs, boîtiers, code — tout est ouvert. Le guide de contribution explique comment travailler sans matériel (mode `--simulate`), ce que vérifie la CI, et où s'arrêter avant de toucher aux frontières de modules ou aux protocoles.
